Image files used by the PFC Example application (`pfcexamp`), and `examples.pbr`, its resource file. They include copies of the pictures of PFC's own objects, from [PFC-Image-Files](https://github.com/OpenSourcePFCLibraries/PFC-Image-Files).

## Which versions of PFC use these files

| Version | Its images |
|---|---|
| [2022](https://github.com/OpenSourcePFCLibraries/2022) | **This repository.** Add its folder to the system path or to PowerBuilder's application path; the Example application's project names `examples.pbr`. |
| [2019](https://github.com/OpenSourcePFCLibraries/2019) | The same images, in that repository. It doesn't need this repository. |
| [2025-Solution](https://github.com/OpenSourcePFCLibraries/2025-Solution) and [2025-Workspace](https://github.com/OpenSourcePFCLibraries/2025-Workspace) | Current images (Fluent UI System Icons) in `examples/images`, and PFC's own in `pfc libs/images`. They don't use this repository. |
